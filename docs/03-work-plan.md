# Work Plan

## المرحلة 0: تثبيت الرؤية والاساس

الهدف: منع التشتت قبل البناء.

- اعتماد اسم المنتج والرسالة التسويقية.
- اعتماد اللغات الاولية: العربية `ar` والانجليزية `en`.
- اعتماد بنية URL متعددة اللغات.
- تجهيز Design tokens للهوية.
- تحديد انواع العملاء والخدمات والمدن السعودية المطلوبة في النماذج.
- تحديد صلاحيات الادارة الاولية.

المخرجات:

- قائمة محتوى نهائية للصفحات.
- خريطة routes.
- مخطط بيانات اولي.
- قرار واضح لطريقة تخزين الترجمات.

## المرحلة 1: البنية التقنية

Backend Laravel:

- تجهيز API versioning مثل `/api/v1`.
- تجهيز Auth للوحة التحكم.
- تجهيز Roles/Permissions.
- تجهيز Media uploads.
- تجهيز Models ومigrations الاساسية.

Frontend Nuxt:

- ضبط `@nuxtjs/i18n`.
- ضبط RTL/LTR.
- بناء layout عام.
- بناء نظام مكونات: Header, Footer, Buttons, Cards, Forms.
- ضبط SEO meta لكل صفحة.

المخرجات:

- مشروع قابل للتشغيل.
- صفحات placeholder متعددة اللغات.
- API health check.

## المرحلة 2: الموقع العام MVP

- الصفحة الرئيسية.
- من نحن.
- الخدمات العامة.
- صفحات الخدمات التفصيلية.
- طلب خدمة.
- تواصل معنا.
- المشاريع.
- FAQ.
- المقالات.
- الصفحات القانونية.

المخرجات:

- موقع عربي مكتمل وظيفيا.
- نماذج ترسل إلى Laravel وتظهر في قاعدة البيانات.
- ادارة محتوى اولية من Seeders او Dashboard بسيط.

## المرحلة 3: لوحة التحكم

- تسجيل دخول.
- ادارة الخدمات.
- ادارة المشاريع.
- ادارة المقالات.
- ادارة FAQ.
- ادارة طلبات الخدمة.
- ادارة رسائل التواصل.
- ادارة العملاء.
- اعدادات الموقع.

المخرجات:

- Admin dashboard usable.
- صلاحيات اولية.
- فلترة وبحث للطلبات والعملاء.

## المرحلة 4: طبقة AI الخفيفة

ابدأ بميزات قليلة ذات اثر واضح:

- تصنيف طلب الخدمة تلقائيا.
- اقتراح المستندات المطلوبة بناء على نوع الخدمة والمدينة ونوع العميل.
- تلخيص طلب العميل للموظف.
- اقتراح رد اولي للمتابعة عبر WhatsApp او البريد.

المخرجات:

- AI لا يقرر نيابة عن الموظف، بل يقترح.
- سجل لكل اقتراح AI.
- امكانية تعطيل AI من الاعدادات.

## المرحلة 5: تحسينات السعودية وSEO

- صفحات landing لخدمات ومدن مختارة.
- Schema.org للخدمات، المقالات، المؤسسة، FAQ.
- تحسين Core Web Vitals.
- مكتبة مقالات موجهة للبحث المحلي.
- ربط WhatsApp بأحداث tracking.

## المرحلة 6: Portal العملاء

- حساب عميل.
- عرض الطلبات.
- حالة المشروع.
- رفع ملفات.
- رسائل وتعليقات.
- اشعارات بريد/WhatsApp لاحقا.

## اولويات التنفيذ

1. i18n/RTL وبنية routes.
2. نماذج طلب الخدمة والتواصل.
3. الخدمات وصفحاتها.
4. ادارة المحتوى.
5. المشاريع والمقالات.
6. لوحة الطلبات والعملاء.
7. AI خفيف.
8. Portal.

## تعريف الانتهاء للـ MVP

- العميل يستطيع فهم الخدمات وطلب خدمة من الجوال.
- الفريق يستطيع استقبال الطلب وتصنيفه ومتابعته.
- الموقع يظهر بشكل صحيح بالعربية ويدعم اضافة الانجليزية دون اعادة بناء.
- جميع الصفحات المهمة لها SEO metadata.
- الملفات المرفوعة مفحوصة ومحددة الحجم والنوع.
