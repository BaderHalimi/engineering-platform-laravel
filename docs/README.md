# Engineering Platform Documentation

هذه الوثائق تعيد تنظيم ملف المشروع الاصلي إلى ملفات قابلة للتنفيذ هندسيا ومنتجيا.

المشروع الحالي مقسوم إلى:

- Backend: Laravel 12 في `engineering-platform-be`
- Frontend: Nuxt 4 في `engineering-platform-fe`
- UI/i18n جاهز مبدئيا في الفرونت عبر `@nuxtjs/i18n`

## التوجه المقترح

بدل بناء موقع تعريفي فقط، يتحول المشروع إلى منصة هندسية ذكية للسوق السعودي والعربي:

منصة تعرض خدمات شركة الديوان للاستشارات الهندسية، تستقبل طلبات العملاء، تساعد العميل على فهم الخدمة المناسبة له، تجمع المتطلبات والمرفقات بطريقة منظمة، ثم تمهد لاحقا لبوابة عميل تتابع حالة الطلب والمشروع.

## ملاحظات تنفيذية سريعة

- ابدأ بالعربية كلغة اساسية، لكن لا تخزن النصوص كحقول عربية فقط. استخدم بنية قابلة للترجمة مثل `title`, `slug`, `summary`, `body` لكل لغة.
- افصل المحتوى التسويقي عن بيانات التشغيل. صفحات الخدمات والمقالات والمشاريع محتوى، بينما طلبات الخدمة والعملاء والملفات بيانات تشغيل.
- اجعل كل نموذج يؤدي إلى lead واضح في لوحة التحكم.
- لا تجعل AI شرطا لاطلاق MVP. ابنه كطبقة مساعدة تبدأ بالتصنيف والاقتراحات، ثم تتوسع إلى مساعد هندسي.
- راع خصوصية العملاء والملفات الهندسية من البداية، خاصة عند استخدام اي مزود AI خارجي.
- طبّق الهوية البصرية كواجهة هندسية منظمة: شبكات، خطوط واضحة، مساحات هادئة، وابراز برتقالي محدود.
