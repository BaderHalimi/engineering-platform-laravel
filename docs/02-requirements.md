# Requirements

## المتطلبات الوظيفية

### الموقع العام

- عرض موقع مؤسسي وتسويقي لشركة الديوان للاستشارات الهندسية.
- دعم العربية كلغة اساسية، مع جاهزية تقنية للانجليزية.
- تصميم Responsive ويدعم RTL.
- صفحات عامة من 18 إلى 22 صفحة تقريبا في المرحلة الاولى.
- استخدام الهوية البصرية للشركة: رسمي، هندسي، موثوق، حديث، راق، واضح.
- الوان معتمدة: Bright Orange, Soft Teal, Light Mist, Warm Ivory, Deep Slate `#3d5057`.

### الصفحة الرئيسية

- Hero حديث يحتوي صور او فيديوهات وحركة بصرية انيقة.
- عنوان واضح للشركة ونبذة مختصرة.
- ازرار رئيسية: اطلب خدمة، تواصل معنا، WhatsApp.
- عرض مختصر للخدمات.
- قسم لماذا الديوان؟
- قسم آلية العمل.
- عرض مختصر للمشاريع.
- بيانات تواصل وروابط مباشرة.

### من نحن

- نبذة عن الشركة.
- الرسالة، الرؤية، والقيم.
- شرائح العملاء المخدومين.
- نقاط القوة.
- صور المكتب او الفريق عند توفرها.

### الخدمات

- صفحة خدمات عامة تعرض الخدمات كبطاقات.
- كل بطاقة تحتوي: اسم الخدمة، وصف مختصر، لمن تناسب، زر معرفة المزيد، زر طلب الخدمة.
- صفحات تفصيلية للخدمات:
  - التصميم واصدار التراخيص.
  - الاشراف الهندسي.
  - الامن والسلامة والدفاع المدني.
  - الواجهات والتصميم الداخلي.
  - ادارة المشاريع.
  - خدمات المساحة.

### صفحة الخدمة التفصيلية

كل صفحة خدمة يجب ان تحتوي:

- تعريف الخدمة.
- من يحتاج هذه الخدمة؟
- ماذا تشمل؟
- خطوات التنفيذ.
- المستندات او المعلومات المطلوبة.
- مزايا تنفيذ الخدمة مع الديوان.
- صور او عناصر بصرية مناسبة.
- CTA واضح لطلب الخدمة.

### المشاريع والاعمال

- عرض المشاريع او نماذج الاعمال.
- تصنيف المشاريع حسب نوع الخدمة.
- لكل مشروع: صورة او اكثر، وصف مختصر، نوع الخدمة، المدينة او الموقع العام.

### طلب خدمة

النموذج يجب ان يجمع:

- الاسم.
- رقم الجوال.
- البريد الالكتروني.
- نوع العميل.
- نوع الخدمة.
- المدينة.
- وصف الطلب.
- رفع ملف اختياري.
- طريقة التواصل المفضلة.

### تواصل معنا

- عنوان الشركة.
- Google Map.
- رقم الهاتف.
- WhatsApp.
- البريد الالكتروني.
- ساعات العمل.
- روابط التواصل الاجتماعي.
- نموذج تواصل سريع.

### الاسئلة الشائعة

- اسئلة واجوبة قابلة للادارة.
- امثلة: الخدمات المقدمة، كيفية طلب خدمة تصميم ورخصة، المستندات المطلوبة، تحديد التكلفة.

### المقالات والمعرفة

- قائمة مقالات.
- تصنيفات.
- صفحة مستقلة لكل مقال.
- مقالات اولية:
  - خطوات اصدار رخصة بناء.
  - متى تحتاج إلى مكتب استشارات هندسية؟
  - الفرق بين التصميم والاشراف.
  - متطلبات الدفاع المدني.
  - نصائح قبل بدء المشروع.

### الصفحات القانونية

- سياسة الخصوصية.
- الشروط والاحكام.

## متطلبات لوحة التحكم

### Admin Dashboard

- تسجيل دخول للمدير والمستخدمين.
- ادارة المستخدمين: اضافة، تعديل، حذف، اخفاء، تعطيل.
- ادارة الصلاحيات: super user, admin, employee, user.
- ادارة اعدادات الموقع: الاسم، البريد، انواع الملفات، احجام الملفات والصور والفيديو.
- تشغيل او ايقاف الموقع مع رسالة للزوار.
- تقارير عامة.
- نسخ احتياطي لقاعدة البيانات.

### User/Client Dashboard

- تعديل الملف الشخصي.
- ادارة الاقسام: الاخبار، المقالات، المشاريع، الخدمات، الاسئلة الشائعة.
- عرض طلبات الخدمة والمتابعة عبر الاتصال او WhatsApp.
- عرض سجلات اتصل بنا.
- ادارة العملاء: اضافة، تعديل، بحث، عرض الملفات والمشاريع، حذف.

## المتطلبات غير الوظيفية

- الاداء: تحميل سريع للصفحات العامة، واستغلال Nuxt prerender للصفحات الثابتة حيث يناسب.
- SEO: عناوين ووصف وstructured data وروابط canonicals لكل لغة.
- الامان: حماية نماذج الادخال، فحص الملفات، rate limiting، صلاحيات واضحة.
- الخصوصية: عدم ارسال ملفات العملاء إلى خدمات خارجية دون سياسة واضحة وموافقة.
- قابلية التوسع: فصل API عن الواجهة ودعم Portal لاحقا.
- القابلية للترجمة: عدم hardcode للنصوص في المكونات.
- قابلية الصيانة: توحيد تصميم المحتوى والكيانات في Laravel.

## خارج نطاق MVP

- تتبع مشاريع كامل بتفاصيل عقود وفواتير.
- دفع الكتروني.
- توقيع الكتروني.
- تكامل مباشر مع منصات حكومية.
- AI يحلل مخططات هندسية او ملفات CAD.
